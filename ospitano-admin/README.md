# OSPITANO Admin

Отделен WordPress плъгин, който облича административния панел в стила на OSPITANO.

- Вход с логото, цветовете и шрифтовете на OSPITANO (без логото и линковете на WordPress)
- Тъмно меню, кремав фон, Montserrat и Cormorant Garamond (шрифтовете са в плъгина, без Google Fonts)
- Без бутона W, новини, версия, известия за обновления и помощни раздели
- Начален екран „Начало“ с бързи бутони вместо стандартните кутии
- Кратко меню за хотела: всички, които не са с „Пълен достъп“, виждат само избраните точки и не могат да отварят системни екрани (плъгини, теми, обновления, инструменти, настройки, потребители)
- Кратък адрес (по избор в настройките): панелът на `/admin`, входът на `/admin/login`. Старите `/wp-admin` и `/wp-login.php` остават като резервен вход. Правилата в .htaccess се пишат само след успешна проверка и се махат при изключване на плъгина; `define( 'OSPA_NO_CLEAN_URL', true );` в wp-config.php ги изключва принудително.
- Бутон „Изглед на хотела“ в горната лента, за да видиш панела както го вижда хотелът

Настройки: Настройки → OSPITANO Admin (само за хора с пълен достъп). Който активира плъгина, получава пълен достъп.

Не пипа резервациите, стаите и съдържанието на сайта. Изключването на плъгина връща стандартния вид.

Zip: `cd .. && zip -r ospitano-admin.zip ospitano-admin -x '*/README.md'`
